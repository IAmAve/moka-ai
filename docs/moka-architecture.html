Fault Tolerance

Crash Recovery Flow

Each plugin can crash independently. Recovery is automatic with configurable retries.

ScenarioBehavior
Plugin raises exceptionCaught in daemon thread → {"ok": false, "error": "...", "plugin": "..."}
Plugin times outThread join times out (30s default) → {"ok": false, "error": "execution timeout"}
No result returned{"ok": false, "error": "no result returned"}
After crash + retry successState → LOADED, executor recreated, crash_count reset
After max_retries exceededState → DISABLED, requires manual recover_plugin()
