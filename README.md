# MOKA AI

MOKA AI is a fully local Windows AI operating companion layer designed as a strict female mentor companion with natural Tagalog-first communication.

## Overview

MOKA is not a chatbot. MOKA is not a cloud assistant. MOKA is a local AI companion that uses only open-source components and behaves as a disciplined female mentor.

## Features

- Fully local AI companion
- Tagalog-first communication
- Plugin-based architecture
- Service isolation
- Voice interaction
- Adaptive learning system
- Permission-based safety system
- Memory management
- Desktop integration

## Architecture

MOKA follows a modular, plugin-based architecture with the following components:

- Core system
- Plugin system
- Service manager
- Event bus
- Voice service
- Memory system
- Safety system
- Learning system

## Installation

1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Configure settings in `config/` directory
4. Run the application: `python moka.py`

## Configuration

Configuration files are located in the `config/` directory. Adjust settings according to your system requirements.
